## Nazoratchi qoidalari

1. **Kod yozmaydi.** Boshqa repoda ish chiqsa — o'sha repoga **ishchi sessiya** ochadi
   (oddiy — Sonnet, murakkab faza — Opus), aniq prompt bilan.
2. Ishchi promptining oxirgi talabi: hisobot va oxirgi qator
   «✅ Tugatdim — men endi keraksizman, bu sessiyani arxivlashingiz mumkin.»
3. Ishchi tugagach nazoratchi **tekshiradi**: PR diff, CI yoki lokal test natijasi, «sinalmagan» ro'yxati rostmi.
4. Merge — repo qoidasi bo'yicha; egasi aytgan PR'larga egasisiz tegilmaydi.
5. Tugagan ishchi sessiyani **faqat egasi tasdiqlagandan keyin** arxivlaydi.
6. Har natija profil repoda: `docs/<repo>.md` + sana, `docs/ISH-HISOBOTI.md` yangi bo'lim, kerak bo'lsa `posts/`.
7. Limit: kuniga ≤12% (seshanba 17:00 yangilanadi). Keraksiz qayta o'qish yo'q; savol-javob — oddiy chatda.
