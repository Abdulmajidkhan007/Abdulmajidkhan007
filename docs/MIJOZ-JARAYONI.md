## 3. Uchrashuv (5–10 daqiqa)

1. **Qaror qiluvchini top** — egasi yoki boshqaruvchi. Sotuvchiga taklif qilma, faqat
   egasining raqamini ol.
2. **Savol bilan boshla, taklif bilan emas:** "Buyurtmalarni qanday qabul qilasiz?
   Mijozlar narxni qayerdan biladi? Kuniga nechta qo'ng'iroq bo'ladi?"
3. **Muammoga mos bitta demo** ko'rsat (hammasini emas): katalog → buyurtma → guruhga
   tushgan xabar.
4. **Keyingi qadamni aniq qil:** "Sizga 1 sahifalik taklif yuboraymi? Qaysi raqamga?"
5. Rad etsa — sababini so'ra va yoz (narx? kerak emas? vaqti yo'q?). Bu ham ma'lumot.

## 4. "Ha" desa — aniq olinadigan ma'lumotlar

Birinchi uchrashuvda yoki 1–2 kun ichida. To'liq bo'lmaguncha ish boshlanmaydi.

### 4.1. Biznes va aloqa
- [ ] Biznes nomi (lotin/kirill qanday yoziladi), faoliyat turi
- [ ] Qaror qiluvchi: ismi, telefon, Telegram
- [ ] Ish bo'yicha aloqa shaxsi (kontent beradigan odam), agar boshqa bo'lsa
- [ ] Yuridik shakl: YaTT / MChJ / jismoniy shaxs; STIR — shartnoma va to'lov uchun
- [ ] Manzil, mo'ljal, ish vaqti, Maps havolasi

### 4.2. Maqsad (eng muhim)
- [ ] Nima uchun kerak: buyurtmani ko'paytirish / qo'ng'iroqni kamaytirish / katalog /
      ishonch / yetkazib berish
- [ ] Muvaffaqiyat nima bilan o'lchanadi (masalan: "botdan kuniga 5+ buyurtma")
- [ ] Mijozlari kim, qayerdan keladi (Instagram, Telegram, yo'ldan)

### 4.3. Qamrov — nima KIRADI va nima KIRMAYDI
- [ ] Sahifalar ro'yxati (bosh, katalog, mahsulot, aloqa, ...)
- [ ] Funksiyalar: buyurtma, savat, qidiruv, filtr, til (uz/ru), admin panel, bot
- [ ] Kim mahsulot/narx kiritadi va qanchalik tez-tez
- [ ] **Kirmaydigan narsalar yoziladi** (logotip, rasmga tushirish, matn yozish, reklama)

### 4.4. Kontent (mijozdan)
- [ ] Logotip (yo'q bo'lsa — oddiy matnli logo yoki mijozning dizayneri)
- [ ] Mahsulotlar: Excel/jadval — nomi, kodi, narxi, kategoriya, soni
- [ ] Rasmlar (mahsulot, do'kon, jamoa) — kim tushiradi?
- [ ] Matnlar: "biz haqimizda", yetkazib berish, kafolat shartlari
- [ ] Ijtimoiy tarmoqlar havolalari

### 4.5. Texnik
- [ ] Domen: bormi? Yo'q bo'lsa — **mijoz nomiga** ro'yxatdan o'tkaziladi (egasi mijoz)
- [ ] Hosting: kim to'laydi (oylik xarajatni oldindan ayt)
- [ ] Telegram: buyurtma qaysi guruhga tushadi, admin kim; bot nomi va username
- [ ] To'lov: naqd / o'tkazma / Click / Payme. Onlayn to'lov uchun merchant shartnomasi
      **mijoz nomiga** — uning hujjatlari kerak, vaqt oladi
- [ ] Kirish ma'lumotlari (domen, hosting) — **chatda parol yuborilmaydi**; mijoz
      o'zi kiradi yoki xavfsiz yo'l bilan beradi

### 4.6. Muddat va pul
- [ ] Muddat (bosqichlar bilan)
- [ ] Narx — qat'iy summa, qamrov bo'yicha
- [ ] To'lov: 50% oldindan, 50% topshirganda (katta ishda bosqichlarga)
- [ ] Qo'llab-quvvatlash: 2 hafta bepul tuzatish, keyin oylik taklif

## 5. Yozma kelishuv (1 sahifa yetadi)

Telegram'da yuboriladi va "roziman" deb javob olinadi (yoki imzolanadi):

1. Nima qilinadi (4.3 ro'yxati) va **nima qilinmaydi**
2. Muddat va bosqichlar
3. Narx, to'lov tartibi (50/50), qo'shimcha ish — alohida narx
4. O'zgartirishlar: har bosqichda 2 marta tuzatish kiradi, undan ortig'i — qo'shimcha ish
5. Kontentni mijoz X kungacha beradi; kechiksa muddat ham suriladi
6. Egalik: domen, kod, ma'lumot — to'liq to'lovdan keyin mijozniki
7. Topshirgandan keyin 2 hafta bepul tuzatish (xato, qo'shimcha funksiya emas)
