# Vizitka

- `vizitka.html` — manba (90 × 50 mm, 2 tomon). Matn shu yerda o'zgartiriladi.
- `vizitka.pdf` — bosmaxonaga (2 sahifa: old va orqa, 90 × 50 mm).
- `vizitka-old.png`, `vizitka-orqa.png` — Telegram'da yuborish va README uchun.
- `qr-sayt.svg` — QR: https://abdulmajidkhan007.github.io/Abdulmajidkhan007/

**Yangilash:** `vizitka.html` ni tahrirla → Playwright bilan qayta chiqar
(`page.pdf({ preferCSSPageSize: true, printBackground: true })` va har `.card` skrinshoti,
`deviceScaleFactor: 4`). Telefon, lavozim yoki xizmatlar o'zgarsa — shu yerda ham.

**Bosmaxonaga:** standart 90 × 50 mm. Bosmaxona chekka (bleed) so'rasa — 2 mm qo'shib
(94 × 54 mm) qayta chiqariladi. Qog'oz: 300 g/m², mat laminatsiya tavsiya etiladi.
